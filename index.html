5. 134/11 Doğrulama Kapısı

Aşağıdaki maddeler “doğrulandı” olarak işaretlenmeden parseli satın alma kararı verme.

1. Kadastro🟢 TKGM'de 134/11 görüldü; alan/nitelik kontrol edildi.
2. Geometri🟢 Haritadaki parsel geometrisi görüntülendi.
3. İmar / plan🟡 Ova Yenice + 134/11 için plan kaydı ayrıca doğrulanmalı.
4. Yol / ulaşım🟡 Kadastro yoluna fiilî ve hukuki bağlantı ayrıca kontrol edilmeli.
5. 18. madde / terk🔴 Resmî belge görülmeden doğrulanmış kabul edilmez.
6. Kısıtlar🟡 Tarım, orman, sit, dere, enerji hattı vb. katmanlar ayrıca kontrol edilmeli.

6. Doğrulama Kayıtları — 134/11

Bu bölüm, parsel hakkında yaptığımız kontrollerin hangi kaynağa dayandığını ve hangi noktaların hâlâ açık olduğunu gösterir.

Kontrol Durum Kaynak Sonuç
Kadastro / parsel DOĞRULANDI TKGM Parsel Sorgu 134 ada / 11 parsel mevcut. Alan 9.065,32 m², nitelik Tarla.
Parsel geometrisi DOĞRULANDI TKGM harita görüntüsü 134/11 parsel geometrisi harita üzerinde görüntülendi.
İmar / plan AÇIK İBB Plan Askı / Çatalca Belediyesi Ova Yenice + 134/11 için kesin plan kararı henüz resmî olarak doğrulanmadı.
Yol / ulaşım AÇIK TKGM + kadastro yolu kontrolü Haritada yol bağlantısı görülüyor; hukuki/fiilî erişim ayrıca doğrulanmalı.
18. madde / terk DOĞRULANMADI Resmî plan / kadastro belgeleri Resmî belge görülmeden “terk yoktur” veya “18. madde yoktur” denilemez.
Tarım / orman / sit / diğer kısıtlar AÇIK Resmî kurum ve harita katmanları Bu kısıtların tamamı henüz sistem tarafından otomatik doğrulanmış değildir.
Arsa Radar kuralı: Bir madde “AÇIK” veya “DOĞRULANMADI” durumundayken sistem parseli “kesin imarlı”, “kesin değerlenecek” veya “satın alınmalı” olarak işaretlemez.

7. Sistem Durumu

Bu V2'nin yaptığı: mevcut aday verilerini filtreler, skorlar, ucuzluk ve bütçe koşullarına göre sıralar ve 134/11 için ayrı doğrulama akışı sunar.

Henüz yapmadığı: TKGM/MEGSİS veya belediye sistemlerinden otomatik canlı parsel/imar verisi çekmez. Canlı resmî API erişimi olmadan “otomatik doğrulandı” sonucu üretmez.

Sonraki teknik aşama: yetkili/erişilebilir resmî servislerden veri alabilen backend + gerçek koordinat/plan katmanı + otomatik değişiklik takibi.
